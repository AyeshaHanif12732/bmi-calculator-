# BMI Calculator

A simple, fast, and responsive web tool to check Body Mass Index (BMI) without needing any account.

## Features
- Free height & weight check
- Instant calculation with health categories
- Simple and easy to use
- Data stays securely on your device

## BMI Categories
- Underweight: < 18.5
- Normal: 18.5 – 24.9
- Overweight: 25 – 29.9
- Obese: ≥ 30

## Disclaimer
This is a simple calculation only — not medical advice. For health decisions, consult a qualified professional.
